## Contents

- `COMP842_Exercise 1.ipynb` — Exercise 1: a blockchain with SHA-256 hashing and
  a Merkle root over each block's records, with tamper detection that reports the
  first invalid block. Themed as an academic records ledger (enrolments, grades,
  and credentials).

## How to run

Open the notebook in JupyterLab (Anaconda) and run all cells top to bottom
(Kernel -> Restart Kernel and Run All Cells). Exercise 1 uses only Python's
built-in `hashlib` and `datetime`, so no extra installation is required.

More exercises will be added as the portfolio progresses.
